# Sweet Bloom — evolução para o PI II

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Evoluir a loja de cupcakes do repositório andersdev23/cupcake-web em uma aplicação com processamento de pedidos no servidor, persistência, administração, testes e documentação para o Projeto Integrador II.

## Users

Cliente que consulta produtos e registra uma encomenda; administrador que acompanha os pedidos e mantém o catálogo.

## Capabilities and Constraints

HTML, CSS e JavaScript existentes; back-end Python e SQLite. Valores em centavos, validação no servidor e administração autenticada. A forma de pagamento é registrada; não há processamento financeiro, cobrança ou integração automática com WhatsApp. Execução local por padrão. A hospedagem estática atual na Vercel não executa esse servidor Python com SQLite persistente.

## Brand Commitments

Preservar Sweet Bloom, a temática de confeitaria e o sistema visual original rosa, marrom e creme. Trabalho autorizado pelo usuário: implementação da evolução para o PI II, incluindo banco, pedidos, painel, testes e documentação. O usuário confirmou que Sweet Bloom foi seu projeto do PI I. Não inventar resultados de avaliações.
